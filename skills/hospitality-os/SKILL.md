Never manual data entry. Never more than one meaningful action per task.

## 6 Modules

### 1. SupplySnap (Supply Chain AI)
- Camera AI reads supplier price boards in <3 seconds
- GPT-4 Vision / Google Cloud Vision extracts SKU, item, price
- Pushes to PurchasePlus API automatically
- Market price benchmarking (Sydney Markets, Bangkok wholesale)
- Alert when supplier price >10% above market
- Origin: Mothy saw PurchasePlus showing stale prices vs real invoices

### 2. RosterIQ (Labour Intelligence)
- Reads booking data → forecasts covers → suggests roster
- True labour cost: base + FICA/Super + workers comp + health + leave
- Integrates with Zambion, Deputy, Humanforce
- AI learns from history: "last 4 Saturdays = 120 covers, roster for 125"

### 3. ProfitPulse (Financial Intelligence)
- Live P&L: revenue from POS, COGS from SupplySnap, labour from RosterIQ
- Weekly report auto-generated every Monday
- AI variance analysis: "food cost up 2.3% — salmon price spike"
- Integrates with Xero, MYOB, QuickBooks, SAP

### 4. TableFlow (Social-Native Booking)
- TikTok native "Book Now" button inside video
- Instagram DM AI: "book Saturday 7pm 2 pax" → confirmed automatically
- LINE integration (Thailand — 52M users)
- Booking feeds RosterIQ → updates cover forecast → adjusts prep sheet
- Bangkok-first launch

### 5. ImmerseDine (AR Preview)
- Meta Quest 3 / Ray-Ban Meta Glass integration
- WebAR — no app download, link in Instagram/TikTok
- 3D food visualisation — see dish in real scale before ordering
- Table selector in 3D floor plan
- World's first social-to-AR-to-booking funnel

### 6. ChefBrain (AI Co-Pilot)
- Natural language: "how did last week go?" → plain English summary
- Daily 7am brief via WhatsApp/LINE
- Voice command mode — hands-free during service
- Cross-module anomaly detection
- Seasonal demand forecasting
