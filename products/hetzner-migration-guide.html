Phase 3
Install Everything — One Master Script
This single script installs Node.js, clones your workspace, installs OpenClaw, sets up the file server, and configures the Discord bot. Copy it, fill in your 3 values, paste it into the server. That's it.
⏱ 20–30 minutes (mostly automated)
8
Fill in your 3 values — then run the master script

Replace these 3 placeholders before running:

  • YOUR_ANTHROPIC_API_KEY — from console.anthropic.com (starts with sk-ant-)
  • YOUR_DISCORD_BOT_TOKEN — from discord.com/developers
  • YOUR_GITHUB_PAT — your GitHub Personal Access Token
#!/bin/bash
# ============================================================
# CLAW SERVER SETUP — Hetzner CX22 · Ubuntu 22.04
# Fill in the 3 values below before running
# Run as: bash setup.sh
# ============================================================

# ── YOUR 3 VALUES ────────────────────────────────────────────
ANTHROPIC_API_KEY="sk-ant-api03-YOUR_KEY_HERE"
DISCORD_BOT_TOKEN="YOUR_DISCORD_BOT_TOKEN_HERE"
GITHUB_PAT="YOUR_GITHUB_PAT_HERE"
GITHUB_REPO="timothysusanto/kitchenfounder-workspace"
# ─────────────────────────────────────────────────────────────

set -e
echo "🚀 Starting Claw server setup..."

# 1. Update system
apt-get update -qq && apt-get upgrade -y -qq
echo "✅ System updated"

# 2. Install Node.js v22
curl -fsSL https://deb.nodesource.com/setup_22.x | bash -
apt-get install -y nodejs
node --version
npm --version
echo "✅ Node.js installed"

# 3. Install git + other tools
apt-get install -y git curl wget unzip htop
echo "✅ Tools installed"

# 4. Create ubuntu user workspace
mkdir -p /home/ubuntu
useradd -m -s /bin/bash ubuntu 2>/dev/null || true

# 5. Clone workspace from GitHub
cd /home/ubuntu
git clone "https://${GITHUB_PAT}@github.com/${GITHUB_REPO}.git" .openclaw/workspace
echo "✅ Workspace cloned from GitHub"

# 6. Install OpenClaw globally
npm install -g openclaw 2>&1 | tail -5
echo "✅ OpenClaw installed"

# 7. Create OpenClaw config directory
mkdir -p /home/ubuntu/.openclaw

# 8. Write the .env file
cat > /home/ubuntu/.openclaw/.env << EOF
ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
DISCORD_BOT_TOKEN=${DISCORD_BOT_TOKEN}
MODEL=anthropic/claude-sonnet-4-5
WORKSPACE=/home/ubuntu/.openclaw/workspace
EOF
echo "✅ .env file created"

# 9. Set up Discord bot dependencies
cd /home/ubuntu/.openclaw/workspace/claw-discord-bot
npm install
echo "✅ Discord bot dependencies installed"

# 10. Write bot .env
cat > /home/ubuntu/.openclaw/workspace/claw-discord-bot/.env << EOF
DISCORD_BOT_TOKEN=${DISCORD_BOT_TOKEN}
ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
CLAUDE_MODEL=claude-sonnet-4-5
SYSTEM_PROMPT_PATH=/home/ubuntu/.openclaw/workspace/products/claw-startup-context.md
EOF
echo "✅ Bot .env written"

# 11. Install PM2 (keeps bot running permanently)
npm install -g pm2
echo "✅ PM2 installed"

# 12. Set up the file server (port 8081) as a systemd service
cat > /etc/systemd/system/claw-files.service << EOF
[Unit]
Description=KitchenFounder File Server (port 8081)
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/.openclaw/workspace
ExecStart=/usr/bin/python3 -m http.server 8081
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable claw-files
systemctl start claw-files
echo "✅ File server running on port 8081"

# 13. Open firewall ports
ufw allow 22/tcp    # SSH
ufw allow 8081/tcp  # File server
ufw --force enable
echo "✅ Firewall configured"

# 14. Set ownership
chown -R ubuntu:ubuntu /home/ubuntu/.openclaw
echo "✅ Ownership set"

# 15. Start Discord bot via PM2
su - ubuntu -c "cd /home/ubuntu/.openclaw/workspace/claw-discord-bot && pm2 start bot.js --name claw-bot && pm2 save"
pm2 startup systemd -u ubuntu --hp /home/ubuntu
echo "✅ Discord bot started via PM2"

echo ""
echo "============================================"
echo "🎉 SETUP COMPLETE!"
echo "============================================"
echo "File server: http://$(curl -s ifconfig.me):8081"
echo "Bot status:  pm2 status"
echo "Bot logs:    pm2 logs claw-bot"
echo "============================================"

How to run it on the server:

Phase 4
Configure OpenClaw — Connect Discord
Point OpenClaw at your Discord channel and your new Anthropic API key. This is what makes you able to chat with Claw exactly as you do now.
⏱ 15 minutes
10
Option A — Use the custom Discord bot (recommended)

Your custom bot (claw-discord-bot/bot.js) is already running via PM2 from the setup script. It uses the Anthropic API directly with your system prompt from products/claw-startup-context.md.

To test it: Go to your Discord server → DM the bot (or mention it in a channel) → type "hello" → it should reply as Claw.

If the bot doesn't respond: Check the logs with pm2 logs claw-bot --lines 50. The most common issues are:
1. Wrong Discord bot token — regenerate at discord.com/developers
2. Bot not invited to your server — use the OAuth2 URL generator in the Discord developer portal
3. Wrong system prompt path — check the SYSTEM_PROMPT_PATH in the bot's .env
# If you need to restart the bot after fixing .env
pm2 restart claw-bot

# Watch live logs
pm2 logs claw-bot

# Edit bot .env if needed
nano /home/ubuntu/.openclaw/workspace/claw-discord-bot/.env
11
Option B — Run full OpenClaw (if you want heartbeats + skills)

If you want the full OpenClaw experience (heartbeats, cron, skills, all the tools I use now), run OpenClaw instead of just the custom bot:

# Switch to ubuntu user
su - ubuntu

# Initialise OpenClaw (first time only)
openclaw init

# Edit the OpenClaw config
nano ~/.openclaw/.env
# Add these lines:
# ANTHROPIC_API_KEY=sk-ant-api03-YOUR_KEY
# MODEL=anthropic/claude-sonnet-4-5
# DISCORD_BOT_TOKEN=YOUR_TOKEN

# Start OpenClaw
openclaw gateway start

# Check status
openclaw gateway status

# Set up as a systemd service (permanent)
openclaw gateway install
Note: If OpenClaw init asks for pairing, follow the QR code pairing process on your phone or use the manual pairing code. This is the same process as setting up a new device.
12
Update the system prompt with your startup files

The bot uses products/claw-startup-context.md as its system prompt. This file should contain the merged content of SOUL.md + USER.md + MEMORY.md key points. Update it now:

# Check what's in the current startup context
cat /home/ubuntu/.openclaw/workspace/products/claw-startup-context.md | head -50

# If it's outdated, regenerate it by copying the key files
cat /home/ubuntu/.openclaw/workspace/SOUL.md > /tmp/system-prompt.md
echo "" >> /tmp/system-prompt.md
cat /home/ubuntu/.openclaw/workspace/IDENTITY.md >> /tmp/system-prompt.md
echo "" >> /tmp/system-prompt.md
cat /home/ubuntu/.openclaw/workspace/USER.md >> /tmp/system-prompt.md
echo "" >> /tmp/system-prompt.md
cat /home/ubuntu/.openclaw/workspace/MEMORY.md >> /tmp/system-prompt.md

cp /tmp/system-prompt.md /home/ubuntu/.openclaw/workspace/products/claw-startup-context.md
echo "System prompt updated: $(wc -c < /home/ubuntu/.openclaw/workspace/products/claw-startup-context.md) bytes"

# Restart bot to pick up new system prompt
pm2 restart claw-bot
