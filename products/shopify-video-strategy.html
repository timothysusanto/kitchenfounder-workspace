Hero Background Video — The "Open Kitchen" Loop
A seamless 8-second loop playing behind the hero headline. No audio. Cinematic kitchen motion — embers, steam, plating action. Subconsciously signals craft and credibility before the user reads a single word.

What it looks like

Slow cinematic push-in on a professional kitchen pass at golden hour. A chef's hands plate a dish in slow motion. Steam rises from a pan. Embers from a wood-fired grill drift upward. 16:9, dark and warm, desaturated slightly so text overlays read clearly. Loops seamlessly.

CLI Command (run after Higgsfield auth)

higgsfield generate create seedance_2_0 --prompt "Slow cinematic push-in on a professional restaurant kitchen pass, golden warm overhead light, chef hands plating a dish in ultra slow motion, steam rising from cast iron pan, glowing embers from wood grill drifting upward, dark dramatic atmosphere, no faces visible, seamless loop-ready ending, 16:9 cinematic, film grain, 8K quality" --aspect_ratio 16:9 --duration 8 --wait

Shopify Embed Code — Replace hero image with video

HTML — paste into page.kitchenfounder.liquid hero section
<!-- Replace static hero-bg-img with this video block --> <video class="hero-bg-video" autoplay muted loop playsinline poster="[FALLBACK_IMAGE_URL]" style="position:absolute;inset:0;width:100%;height:100%;object-fit:cover;z-index:1;opacity:0.5"> <source src="[HIGGSFIELD_VIDEO_URL]" type="video/mp4"> </video>
Performance tip: Upload the Higgsfield MP4 to Shopify Files (Admin → Settings → Files) to get a permanent CDN URL. Never hotlink directly from Higgsfield — URLs expire. Shopify CDN = permanent + fast global delivery.

Integration
How Videos Embed in the Shopify Pages

Landing Page Hero — Video Background

  • Upload MP4 to Shopify Files → get CDN URL
  • Replace hero-bg-img tag with <video autoplay muted loop>
  • Poster image = static fallback for slow connections
  • CSS: position:absolute;object-fit:cover;opacity:0.5
  • Dark overlay stays on top — text always readable

Product Page — Book Explosion Video

  • Upload per-guide MP4 to Shopify Files
  • Store URL in product metafield: kitchenfounder.hero_video_url
  • Liquid: {{ product.metafields.kitchenfounder.hero_video_url }}
  • Video plays on hover or autoplay muted
  • Static image fallback if no video metafield

Mobile Performance

  • autoplay + muted + playsinline = required for iOS Safari
  • Compress to 720p max for mobile
  • poster attribute = instant visible frame before video loads
  • Consider: pause video on mobile, show poster only (bandwidth)

  • Post to @kitchenfounder TikTok organically first
