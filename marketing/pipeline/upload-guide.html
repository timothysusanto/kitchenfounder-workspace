Step-by-step for Shopify + Etsy
Every time. No exceptions.
Before You Start
Every time you complete a new guide, follow these steps in order:
1. Convert to PDF → 2. Screenshot the Cover → 3. Upload to Shopify → 4. Upload to Etsy
Takes about 45 minutes total once you know the steps.
🛍
SHOPIFY UPLOAD
1
Convert the HTML Guide to PDF
Open the guide in Chrome using the server URL:
http://54.251.18.206:8081/restaurant-pdfs/v7/[filename].html
Chrome Print Settings
Press Ctrl+P (Windows) or CMD+P (Mac)
Destination: Save as PDF
Paper size: A4
✅ Background graphics: ON ← most important!
Click Save → name it [concept]-kitchenfounder.pdf
2
Screenshot the Cover Image
Open the cover file in Chrome:
http://54.251.18.206:8081/shopify-covers/[concept]-cover.html
DevTools Screenshot Method
1. Press F12 to open DevTools
2. Click the 📱 device icon (top left of DevTools)
3. Set width: 1200 and height: 1200
4. Press Ctrl+Shift+P → type "screenshot"
5. Click "Capture full size screenshot"
6. Save as [concept]-cover.png
3
Create the Shopify Product
Go to kitchen-founder.myshopify.com/admin → Products → Add product
Fill In These Fields
Title: [Cuisine] Restaurant Operations Guide — Recipes, Food Costs, Service Scripts & P&L Model

Description: Paste from /workspace/marketing/etsy/etsy-listings.md

Price: $29.99    Compare at: $49.99

Variant: Must say "Default Title" ← critical for downloads

Image: Upload the cover .png you just made
⚠️ CRITICAL: Scroll down to the SEO section. Fill in the meta title and description. Without this, Google won't find your product.
4
Set Up Pendora Downloads
This links your PDF to the product so customers can download it after purchase.
Pendora Steps
1. Go to Apps → Pendora Downloads
2. Find your new product
3. Click Add file
4. Upload the PDF
5. Check variant = Default Title
6. Test it: add to cart → checkout → confirm download appears ✅
5
Add to Collections
Every guide must be in the right collections so customers can find it.
  • All Guides (every product goes here)
  • Relevant cuisine collection (Asian / Latin / Mediterranean)
  • New Arrivals (remove after 30 days)
🏪
ETSY UPLOAD
1
Start a New Listing
Go to kitchenfounder.etsy.com → Shop Manager → Listings → Add a listing
First Thing to Select
When Etsy asks what type of listing — choose "Digital download"
This tells buyers it's an instant download (no shipping)
2
Write the Title (Follow This Formula)
Etsy titles must be keyword-rich. Use this exact formula:
[Cuisine] Restaurant Operations Guide | Recipes, Food Costs, Service Scripts, P&L Model | Instant Download
Example Titles
Sri Lankan Hoppers Restaurant Guide | Recipes, Arrack Cocktails, Kitchen Design, P&L | Instant Download

Spanish Tapas Bar Operations Guide | Recipes, Service Scripts, Kitchen Design, P&L | Instant Download

Max 140 characters. Always end with "Instant Download".
3
Add 13 Tags
Etsy gives you exactly 13 tags. Use all 13 every time. Mix from this formula:
3 Cuisine Tags (change per listing)
e.g. "sri lankan food guide" · "hoppers restaurant" · "ceylon cuisine"
3 Format Tags (always the same)
"restaurant operations guide" · "food business plan" · "restaurant startup guide"
4 Buyer Intent Tags (always the same)
"how to open a restaurant" · "restaurant business plan" · "food cost calculator" · "restaurant menu template"
3 Trending Tags (always the same)
"digital download" · "instant download" · "small business tools"
4
Upload Photos and File
Etsy lets you add multiple photos — use this to show what's inside the guide.
  • Photo 1: Cover image (1200×1200 PNG) ← your main photo
  • Photo 2: Screenshot of a recipe page from inside the guide
  • Photo 3: Screenshot of the P&L model or service scripts
  • File upload: The PDF (max 20MB on Etsy)
💡 Tip: More photos = more trust = more sales. Show buyers what they're getting inside the guide.
5
Set Price and Category
Use these settings every time — don't change them.
Pricing Settings
Price: $29.99 USD
Quantity: 999 (unlimited — it's digital)
Renewal: Automatic
Processing: Instant (auto-delivery)
Returns: No returns on digital downloads
Category
Craft Supplies & Tools → Patterns & How To → Guides & How Tos
6
Paste the Description
The listing description is already written for you.
Where to Find It
Open: /workspace/marketing/etsy/etsy-listings.md
Find the listing for this guide (e.g. "LISTING 7 — Sri Lankan Hoppers")
Copy the full description and paste it into Etsy
💡 Add this line at the very top of the description:
⭐⭐⭐⭐⭐ "Exactly what I needed to plan my restaurant opening" — KitchenFounder customer

ETSY UPLOAD
1
Prepare Your Listing Images
Etsy allows up to 10 images. Use them all. First image = cover. The rest = inside pages.
Image Checklist
Image 1: Cover screenshot (1200×1200px, same as Shopify)
Images 2–4: Interior page screenshots (show the content!)
Image 5: Table of contents / overview page
Images 6–10: Sample recipes, cost sheets, scripts

❌ No text overlays. No watermarks. Clean screenshots only.
2
Create a New Etsy Listing
Go to etsy.com/your/shops/KitchenFounder/tools/listings → Add a listing
Listing Type Settings
Who made it: I did
What is it: A finished product
When was it made: 2020–2025
Category: Paper & Party Supplies → Printables
Type: Digital download
3
Write the Title & Description
Etsy SEO lives in your title. Pack it with keywords buyers actually search.
TITLE FORMULA:
[Cuisine] Restaurant Business Plan Bundle | Recipes, Food Cost Calculator, Staff Scripts, P&L Template | Digital Download
Description
Copy the description from /workspace/marketing/etsy/etsy-listings.md

Make sure it includes:
✅ What's inside (bullet list)
✅ Who it's for
✅ What format (PDF, instant download)
✅ "No refunds on digital items" note at bottom
4
Set Price & Upload the PDF
Digital listings on Etsy don't have shipping — just price and file.
Pricing & File
Price: $27.00 (Etsy takes ~$3.25 in fees → ~$23.75 net)
Quantity: 999 (unlimited digital)

Scroll to "Digital files" section
Click Upload file → select [concept]-kitchenfounder.pdf
Wait for upload to complete ✅
💡 Tip: Etsy file size limit is 20MB. If your PDF is larger, compress it first using ilovepdf.com → Compress PDF.
5
Add Tags (All 13)
Tags are your SEO. Use all 13 slots. Each tag can be a short phrase.
Suggested Tags Template
restaurant business plan · food cost calculator · recipe template · restaurant operations · kitchen manager guide · food profit margins · menu costing · restaurant startup · hospitality templates · restaurant finances · food service guide · restaurant staff training · [cuisine type] restaurant
6
Preview & Publish
Before you hit Publish, do a final check.
  • All 10 images uploaded and in the right order
  • Title has the cuisine type and key search terms
  • Description is complete with bullet list of contents
  • Price is $27.00
  • PDF file is attached and shows green ✅
  • All 13 tags filled in
  • Category: Paper & Party → Printables → Digital
💡 After publishing: Share the Etsy link in the #new-listings Discord channel and pin a note in the marketing tracker spreadsheet.
