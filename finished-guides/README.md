# Finished KitchenFounder Guides

**This folder is intentionally separated from `restaurant-pdfs/` and `products/`.** Those contain drafts, iterations (v2–v8), and unrelated business documents. Everything here is a checked, complete, final 2026-edition guide — nothing else lives in this folder.

**Naming convention:** `guides/{guide-number}-{cuisine-slug}.pdf` — the number matches the guide's own cover page ("GUIDE #NN").

## Note on repo location
This started as a plan for a dedicated new repo. It landed here instead because the available access token was scoped to this repo only (no repo-creation permission), and re-scoping was deprioritised to save time. If a dedicated repo is wanted later, this folder can be split out with `git subtree split` without losing history.
