## ⭐ PARALLEL SUBAGENT METHOD — CONFIRMED BEST PRACTICE
Mothy confirmed: use UP TO 10 parallel subagents for large file builds.

### The Method:
1. Split document into logical sections
2. Fire ALL sections simultaneously as sessions_spawn subagents (runtime=subagent, mode=run)
3. Each subagent uses `cat >> file.html << 'EOF' ... EOF` heredoc
4. Each completes in ~2-3 min independently
5. Wait for all push-based completion events, verify line count
6. Works reliably up to 10 parallel subagents

### Key Rules:
- Each subagent writes ONE section only (small = fast + reliable)
- First chunk: `cat >` (create) with html/head/CSS/body opening
- Middle chunks: `cat >>` (append)
- Last chunk: must close </div></body></html>
- Always verify with `wc -l` echo at end
- NEVER poll — wait for push-based completion events

### Capacity:
- Previous working limit in mind: 5 subagents
- CONFIRMED by Mothy: 10 subagents is fine
